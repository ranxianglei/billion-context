# website — billion-context site

Static landing page + docs + blog + article library. No build step, no dependencies — plain
HTML/CSS/JS (the two `tools/build-*.mjs` generators are zero-dependency Node scripts, not a build chain).
Deployed to [GitHub Pages](https://ranxianglei.github.io/billion-context/) by
`.github/workflows/pages.yml` (publishes this folder on every push to master, plus a half-hourly
scheduled re-render so synced articles lag the repository by at most 30 minutes).

## Local preview

```bash
cd website
python3 -m http.server 8090
# → http://127.0.0.1:8090/
```

All asset references are **relative** so the pages work under any mount path
(`https://<user>.github.io/<repo>/`, subfolder, nginx root, custom domain).

## Generated pages

| generator            | input                                            | output                                          |
| -------------------- | ------------------------------------------------ | ----------------------------------------------- |
| `tools/build-blog.mjs` | `blog/posts/<date_slug>[.zh].md`               | `blog/*.html`, `blog/index.html`                |
| `tools/build-articles.mjs` | `articles.json` manifest → repo markdown (paper/, root *.md, …) | `docs/articles/*.html`, `docs/assets/<slug>/` |

The article library only publishes files listed in `articles.json` — explicit over implicit,
so internal notes (devlog etc.) stay off the public site unless someone adds them there.
Add an entry, run `node tools/build-articles.mjs`, commit the generated output.

## Files

| file                 | purpose                                                          |
| -------------------- | ---------------------------------------------------------------- |
| `index.html`         | landing page; EN strings are the default                         |
| `styles.css`         | design system, light/dark via `prefers-color-scheme`             |
| `main.js`            | EN/中文 toggle (persisted in localStorage), copy buttons, scroll reveal |
| `docs/index.html`    | bilingual /docs/ page (parameter reference is CI-guarded)        |
| `docs/articles/`     | long-form repository articles, generated by `tools/build-articles.mjs` |
| `articles.json`      | manifest of which repository markdown files are published        |
| `config-reference/`  | YAML seeds for the /docs/ parameter reference (`tools/gen-config-docs.mjs`) |
| `blog/`              | posts (markdown in `blog/posts/`) and generated pages (`tools/build-blog.mjs`) |
